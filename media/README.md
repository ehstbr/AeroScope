# Screenshots do AeroScope

Estas capturas de tela foram disponibilizadas pelo autor do projeto e otimizadas em WebP para apresentação no README. São imagens estáticas que representam momentos específicos, não posições atuais de aeronaves.

**Aviso de atribuição:** os mapas, fotografias, dados e marcas visíveis nas capturas podem estar sujeitos a direitos e políticas de terceiros, incluindo os provedores de tiles e de fotografias. A licença MIT do código não transfere direitos sobre esse material externo. Mantenha os créditos exibidos nos mapas e preserve atribuições aplicáveis.

As imagens desta pasta ficam fora de `assets/` intencionalmente para **não serem copiadas pelo script de empacotamento do aplicativo**.
